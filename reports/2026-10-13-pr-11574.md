Adds expandable hourly precipitation tables to the weather panel: two-hour slots for the next 24 hours and six-hour quarters for later days. MET Norway supplies precipitation amounts and temperature; Open-Meteo supplies probability. The existing provider credit and per-coordinate cache remain.

The MET fetcher stores cache metadata as JSON and validates timestamps before using them in Bash arithmetic. Remote Last-Modified headers are read and passed to curl as literal data; cache files are never sourced. Legacy shell-format metadata is ignored and replaced after a successful fetch. This addresses the metadata execution reported in [the review](https://github.com/omacom/omarchy/pull/11574#issuecomment-5849587295).
